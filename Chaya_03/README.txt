PASSWORD GENERATOR

How to run:
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Install the VS Code "Live Server" extension if you do not already have it.
4. Right-click index.html -> Open with Live Server.
5. The Password Generator will open in your browser.

No backend or database is required. This is a full front-end application using:
- HTML
- CSS
- JavaScript

The generator uses the browser Web Crypto API (crypto.getRandomValues) for stronger random generation and works offline after loading.
