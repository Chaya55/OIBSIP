# WeatherNow - Full Stack Weather Application

A ready-to-run weather application built with HTML, CSS and JavaScript.

## Features
- Search weather by city
- Current temperature
- Feels-like temperature
- Humidity
- Wind speed
- Precipitation
- 6-day forecast
- Rain probability
- Use browser location
- Responsive design
- No API key required

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Open-Meteo Geocoding API
- Open-Meteo Weather API

## Run with VS Code Live Server
1. Extract the ZIP.
2. Open the `weather_app` folder in VS Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html`.
5. Select **Open with Live Server**.

The browser will open the application.

## Important
This project uses public Open-Meteo endpoints, so an internet connection is required for live weather data.

For a true production backend, you can later add Node.js/Express as a proxy layer, database storage, user accounts, caching, and API security.
